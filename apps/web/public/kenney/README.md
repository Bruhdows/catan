# Kenney CC0 game assets (curated)

Only the images and sounds used by the Catan client are shipped here. The original complete packs are from [Kenney](https://kenney.nl/) and are **CC0**, including commercial use. Each included pack preserves its upstream `License.txt`.

- **Board Game Icons:** six die faces and the winner crown
- **Emotes Pack:** 16 supported reaction faces in Vector Style 3
- **Interface Sounds:** six sound cues used by `src/sound.ts`

Unused variants, formats, previews and unrelated UI packs are intentionally omitted to reduce the deployment size. Custom cursors are maintained separately under `/art/cursors/` with their own source sprites and license in `apps/web/scripts/kenney-cursors/`.
